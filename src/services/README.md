# Services

Application/business logic belongs here. Keep UI components thin.

Planned areas:

- `ai/` — provider adapter, prompts, structured schemas, generation
- `planning/` — target calculations and plan orchestration
- `grocery/` — ingredient normalization and consolidation
- `pricing/` — mock/curated pricing abstraction
- `budget/` — budget comparison and optimization logic

Do not create abstractions until a real feature needs them.
